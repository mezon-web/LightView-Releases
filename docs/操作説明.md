# LightView 0.2.5

長い技術文書を、軽快に閲覧・検索・文字コピーするための文書ビューワです。

## 起動

ZIPを展開し、フォルダ内の `LightView.exe` を起動してください。
起動フォルダにあるのは `LightView.exe` と補助フォルダ `_support` の2つです。
`_support` には表示に必要なDLL・素材・ライセンス・操作説明が入っています。EXEと一緒に保存してください。
起動時の自己展開は行いません。使い方は右端の「？」またはF1で確認できます。
Windows x64と **.NET 10 Desktop Runtime x64** が必要です。.NETは同梱していません。
インストールやPDFの関連付けの変更は行いません。

対応ファイルをウィンドウへドロップするか、「開く」から選択します。
すでに文書を表示しているウィンドウに別の文書を開くと、別ウィンドウで表示します。
複数の対応ファイルをまとめてドロップすることもできます。

コマンドラインからは `LightView.exe "C:\資料\仕様書.pdf"` で開けます。

「開く」の右にある「履歴」には、最近開いた対応ファイルのファイル名を新しい順に最大10件表示します。
マウスを乗せるとフルパスを確認できます。同じファイルを開き直すと先頭へ移動します。
文書表示中に履歴から選ぶと別ウィンドウで開きます。開けなかったファイルは追加しません。
履歴は `%LOCALAPPDATA%\LightPDF\recent-files.json` に保存し、アプリを終了しても残ります。
履歴にパスワードやPDFの内容は保存しません。移動・削除されたファイルは、開くときにエラーを表示します。
配布フォルダを更新しても履歴は保持します。

文書を開いていない間は、ページ操作・幅合わせ・全体表示・透かし・目次・更新を隠します。
文書を開くと形式に応じた操作を表示します。読み込みに失敗した場合やパスワード入力をキャンセルした場合も、専用操作は表示しません。

## 操作

ツールバー右端の「？」またはF1で、アプリ内のヘルプを開きます。
「基本操作」「PDF」「Markdown・HTML」「TXT・LOG」「CSV・TSV」のタブで使い方を確認できます。
ファイルを開いていないときやWebView2未導入時も利用できます。ヘルプはオフラインで表示し、
文字を選択してCtrl+Cまたは右クリックでコピーできます。Escまたは「閉じる」で閉じます。
ヘルプを開いたまま文書を操作できます。同じウィンドウから繰り返し開いてもヘルプは1つだけ表示します。

| 操作 | 方法 |
| --- | --- |
| ファイルを開く | Ctrl+O / 開く / ドロップ |
| 最近開いたファイルを開く | 開くの右の「履歴」から選択 |
| ヘルプを開く | 右端の「？」 / F1 |
| 文書内を検索 | Ctrl+F / 検索 |
| 検索結果の一覧 | 検索バーの「一覧」で開閉 / 左の項目を選んで移動 |
| 次の検索結果 | 検索欄でEnter / F3 / 次へ |
| 前の検索結果 | 検索欄でShift+Enter / Shift+F3 / 前へ |
| 検索を閉じる | 検索欄でEsc / × |
| 文字を選択 | 文字の上からドラッグ |
| 文字をコピー | Ctrl+C / 右クリック → コピー |
| ページを指定 | ページ番号欄に入力してEnter |
| 拡大縮小 | Ctrl+ホイール / Ctrl++ / Ctrl+- / 倍率欄に入力してEnter |
| 表示範囲を調整 | 幅に合わせる / 全体表示 |
| 斜め透かしを非表示 | 斜め透かしを非表示（もう一度押すと表示） |
| 画像PDFの現在のページを認識 | OCR（利用可能な環境だけ表示。処理中は「中止」） |
| スクロール | ホイール / スクロールバー / 矢印キー |
| 大きくスクロール | PageUp / PageDown |
| 文書の先頭・末尾 | PDFはHome / End、テキストはCtrl+Home / Ctrl+End |

## 検索とコピー

検索は文書全体を対象とする文字列検索で、英字の大文字小文字は区別しません。
正規表現は使用しません。検索件数は調べ終わったページから順に増えます。
検索中でもページ移動やコピーができ、別の検索語に変更すると古い検索を取り消します。
検索用テキストはメモリに再利用するため、2回目以降の検索は速くなります。

検索バーの「一覧」を押すと、左に検索結果のパネルを表示します。
各項目にページ番号と前後の短い抜粋を表示し、検索語を黄色で強調します。
クリックすると該当箇所へ移動します。「前へ」「次へ」やEnterと一覧の選択は連動します。
一覧にフォーカスして上下キーで結果を選び、Enterでその箇所へ戻ることもできます。
検索が完了する前から項目を選べます。結果が増えても一覧で見ている位置を保ちます。
一覧と本文の境界をドラッグすると、一覧の幅を220～360DIPに調整できます。
一覧の×は一覧だけを閉じ、検索欄の×やEscは検索と一覧を閉じます。
一覧の表示と幅はそのウィンドウ内で覚えます。検索を開き直すと、残っている検索語で再検索します。
抜粋の順序や文章の区切りは、PDF内部のテキスト情報に依存します。

文字選択は複数行・複数ページに対応します。ドラッグしたまま画面の上下端へ
近づけると自動スクロールします。逆方向へドラッグしても選択できます。
コピーした内容はプレーンテキストです。
行末より右の余白へドラッグすると、その行の末尾まで選択します。
短い次の行へ下げた場合も、真上の長い行へ選択の終点が戻らず、次の行を選択できます。

画像のみのPDFでは、利用可能な環境で「OCR」を押すと現在のページを検索・コピーできるようになります。未認識のページには文字情報がありません。
段組みや特殊な文字のコピー順序はPDF内部の文字情報に依存します。
PDFのコピー制限に従います。パスワードは保存しません。

閲覧中の下端には操作ガイドや文字コピー対応の常駐説明を表示しません。
読み込み中、エラー、コピー完了などの通知を表示します。

## Windows標準OCR

Windows標準OCRを実際に使える環境では、PDFを開くと「OCR」が表示されます。画像だけのページへ移動して押すと、そのページを認識します。認識後は通常の検索・検索結果一覧・文字選択・Ctrl+C・右クリックコピーを使えます。処理中は「中止」で取り消せます。

文字情報があるページは元の文字情報を使います。認識は現在のページだけで、全ページの一括処理は行いません。結果はそのウィンドウのメモリ内に最大64MiB保持し、終了時に破棄します。PDFは書き換えません。透かしの表示を切り替えると認識結果を破棄します。

追加のOCRライブラリやモデルは同梱せず、Windowsに導入済みのOCR言語を使用します。API・言語・実際の認識を確認できない場合、PDF以外、未読込の画面ではボタンを隠します。PDFでコピーが禁止されている場合は使用できません。

OCRは誤認識する場合があります。文字ごとの位置は単語の枠から推定するため、選択の強調位置は元から文字情報があるPDFほど正確ではありません。日本語などの文字間にOCRが挿入する空白を結合します。詳しい実装と検査記録はソースZIPの `docs/Windows標準OCR.md` を参照してください。

## Markdownプレビュー

`.md` または `.markdown` を開くと、見出し・表・コード・チェックリスト・ローカル画像・Mermaidの図・数式を表示します。編集はできません。UTF-8を基本とし、UTF-16 BOMも読み取ります。数式は `$...$`（文中）と `$$...$$`（独立表示）、Mermaidは `mermaid` のコードブロックで記述します。

外部エディタで保存すると約300msの待ち合わせ後に自動更新します。「更新」またはF5でも読み直せます。更新後も倍率・検索語・読む位置を維持します。段落が削除された場合は同じ見出し内の位置、見出しもなくなった場合はスクロールの比率を使います。読み込みに失敗しても前の表示を残し、次の保存やF5で復帰します。

検索とコピー、左の検索一覧を使えます。検索対象は本文・見出し・表・コードで、図内部と数式は除きます。一覧には近くの見出しと本文ブロックの開始行を表示します。拡大縮小は25～500%で、「幅に合わせる」は100%へ戻します。PDF用のページ操作・透かし操作は表示しません。

画像の相対パスはMDのフォルダが基準です。Web上の画像は自動取得しません。Webリンクは既定ブラウザ、ローカルの対応文書リンクは別ウィンドウで開きます。図や数式に構文エラーがある場合は、その記述と短いエラーを表示します。

MarkdownとHTMLの表示にはWebView2 Runtimeが必要です。未導入なら「公式ダウンロードページを開く」「再試行」「閉じる」を表示します。導入後は同じ画面で再試行できます。初期化エラーは未導入と区別して理由を表示します。PDFはWebView2なしで利用できます。

.NETとWebView2 Runtimeは同梱していません。図・数式のJavaScriptとフォントは同梱済みで、表示時にCDNやNode.jsは使いません。WebView2のプロファイルは `%LOCALAPPDATA%\LightPDF\WebView2` です。図・数式のキャッシュ上限は32MiBで、WebView2プロセス全体の上限ではありません。

## 斜め透かしの非表示

非表示にできる斜めのテキスト透かしが見つかったPDFだけ、「斜め透かしを非表示」を表示します。
初回描画後、バックグラウンドで文書全体を確認します。確認中や対象がないPDFではボタンを隠します。
先頭以外のページにだけ対象がある場合も表示します。ボタンを押すと、斜めのテキスト透かしを非表示にします。
非表示にした透かしは検索・文字選択・コピーの対象からも外れます。
非表示にした後も「斜め透かしを表示」を残し、押すと元に戻ります。元のPDFファイルは変更しません。
設定はそのウィンドウだけに適用し、別のPDFでは元の表示から始まります。

対象は、おおむね30～60度の斜めの文字で、不透明度が80%以下で、長い文字列または日時を含むものです。
輪郭線がある場合は、その不透明度も80%以下である必要があります。
画像に焼き込まれた透かし、水平・垂直の文字、不透明な文字、短い図のラベルは対象外です。
判定は推定なので、本文が消える場合はボタンで表示に戻してください。
切り替え時は文字位置を読み直すため、現在の文字選択を解除します。
検索欄が開いている場合は、その検索語で検索し直します。

## 対応範囲

- 縦方向の連続表示、10～800%の拡大縮小、混在するページ寸法・回転・CropBoxに対応します。
- PDFは読み取り専用で開き、内容を変更しません。
- 4GiBを超えるファイルは、この版の読み込みAPIの対象外です。
- 編集、印刷、タブ、フォーム入力、PDF内JavaScriptの機能はありません。
- エラー画面の説明は選択・コピーできます。

## 軽快な表示のための構成

画面周辺だけを512ピクセルのタイルで描画し、周辺を先読みします。
拡大縮小中は既存の画像を使い、操作後に鮮明な画像へ置き換えます。
キャッシュの上限は画像256MiB・検索テキスト64MiB・OCR結果64MiB・結果の抜粋1MiBです。OCRを使用しない間、OCRキャッシュは空です。
これはキャッシュ自体の上限で、アプリ全体のメモリ上限ではありません。
大きな画像やフォントを含むPDFではPDFエンジンやGPU側にもメモリを使用します。

## 目次・PDF内リンク

「目次」を押すと、PDFのしおり、Markdown・HTMLの見出しを左に表示します。階層は字下げで示し、項目をクリックすると移動します。検索結果一覧と切り替えて利用できます。目次がないPDFは「目次はありません」と表示します。

PDFのリンクはマウスを乗せると手形になり、クリックで同じPDF内のページ・位置へ移動します。HTTP(S)リンクは既定ブラウザで開きます。文字をドラッグして選択したときはリンクを開きません。PDF内のJavaScriptやアプリ起動アクションは実行しません。

## コードの色分け・コピー

Markdownのコードブロックに cs・cpp・python・javascript などの言語名を付けると色分けします。「コピー」はコード本文全体をコピーし、表示用の改行はLFです。不明な言語や10万文字以上のコードは通常表示します。色分け後も本文検索・ドラッグ選択を利用できます。

## TXT・LOG

`.txt`・`.log` は行番号付きの読み取り専用表示です。文字選択、Ctrl+C・右クリックコピー、行番号付きの検索一覧、25～500%の拡大縮小に対応します。保存すると約300ms後に更新し、F5でも再読込できます。UTF-8とBOM付きUTF-16を使用します。

LOG上部の「追記に追従」をONにすると、追記後に末尾へ移動します。初期状態はOFFで、読む位置を維持します。追記時は増えた分だけ読み込みます。ファイルの置換や短縮では全体を読み直します。読み込みに失敗した場合は前の本文を残します。

## CSV・TSV

`.csv`・`.tsv` を表で表示します。先頭行を見出しとして固定し、列の境界をドラッグして幅を変更できます。「先頭行を見出し」をOFFにすると全行がデータになります。区切りや改行を含む引用符付きセル、二重引用符、末尾の空セルに対応します。

検索は画面外の行も含む全セルが対象です。一覧から選ぶと該当セルへ移動します。セルを選んでCtrl+Cまたは右クリックの「コピー」でコピーします。複数セルはタブで区切ったテキストになります。表示は長いセルの先頭2,048文字までで、省略しても検索・コピーは全内容です。元の改行はコピー時に保持します。保存の自動更新とF5に対応します。

## HTML

`.html`・`.htm` は静的なページとして表示します。ローカル画像・CSS・フォントはHTMLのフォルダを基準に解決します。本文検索、文字コピー、見出し目次、保存時の自動更新、ズームとF5を使えます。HTMLの検索一覧は近くの見出しを示します。

スクリプト、イベント属性、フォーム、iframe等を除き、外部リソースは自動取得しません。スクリプトに依存するページは静的な部分だけ表示します。WebView2 Runtimeが未導入なら、MDと同じ案内と再試行を表示します。

## 改名時の互換性

LightPDFからLightViewへ改名しました。EXEとZIPはLightViewになり、履歴とWebView2設定は `%LOCALAPPDATA%\LightPDF` をそのまま使用して引き継ぎます。旧版を起動するショートカットを使っている場合は、新しいLightView.exeを指定してください。
